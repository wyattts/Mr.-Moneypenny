# Third-party notices

Mr. Moneypenny is licensed under AGPL-3.0-or-later — see `LICENSE` at
the repository root.

This directory documents the open-source dependencies that Mr.
Moneypenny embeds, broken out by language ecosystem:

- `THIRD_PARTY_RUST.md` — Rust crates (generated by
  [`cargo-about`](https://github.com/EmbarkStudios/cargo-about))
- `THIRD_PARTY_NPM.txt` — npm packages (generated by
  [`license-checker-rseidelsohn`](https://github.com/RSeidelsohn/license-checker-rseidelsohn))

Both are regenerated by running:

```
bash scripts/generate-notices.sh
```

The generated files are committed to the repo and shipped inside the
release bundle so end-users can read them without rebuilding.

> Note: the Rust notices file also embeds the AGPL-3.0-or-later text
> because cargo-about always includes the root workspace crate
> (`moneypenny`) in its dependency graph. That AGPL block describes
> Mr. Moneypenny itself; the canonical copy is `LICENSE` at the
> repository root.
